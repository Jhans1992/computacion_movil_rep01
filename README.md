# Calculadora Tkinter

Aplicación de calculadora básica creada con Python y Tkinter. Permite realizar operaciones de suma, resta, multiplicación y división. También incluye botones para limpiar la entrada y calcular el resultado.

## Requisitos

- Python 3.8 o superior.
- Tkinter (incluido por defecto en la mayoría de instalaciones de Python).

## Ejecución

```bash
python calculadora_tkinter.py
```

Se abrirá una ventana con la calculadora lista para usarse.
